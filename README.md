# Mohamad Zeidan, teaching e-portfolio

Static site for GitHub Pages. No build step: `index.html` plus the `img/` folder.

## Put it online (about 15 minutes, free)

1. Create a free account at github.com (if you don't have one).
2. Create a new repository named exactly `YOURUSERNAME.github.io` (Public).
3. On the repository page choose "Add file" > "Upload files", drag in `index.html`, `README.md` and the whole `img` folder, then "Commit changes".
4. Go to Settings > Pages. Under "Build and deployment" pick "Deploy from a branch", branch `main`, folder `/ (root)`, Save.
5. After a minute or two the site is live at `https://YOURUSERNAME.github.io`.

To edit text later: open `index.html` on GitHub, click the pencil icon, change the text, commit. The site updates by itself.

## Where things are in index.html
- Courses: the section with id "teaching"
- Projects: id "projects"
- Outreach (EWB, Ethiopia, aquaponics): id "outreach"
- Awards and mentoring: id "recognition"
- Photos: the `img/` folder; swap a file with the same name to replace a picture.
